# Worst Superpower

Entry for the make.fun competition
[u-suroto-worst-superpower-461dcdbe](https://make.fun/c/u-suroto-worst-superpower-461dcdbe)
by [@hifikun](https://make.fun/profiles/hifikun).

## The entry

> I can read my houseplants' minds, but only while I'm asleep, so I wake up remembering nothing, except the fern is disappointed in me.

One line, 133 characters: a superpower so useless that using it teaches you
nothing at all — except that the fern is disappointed in you.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else is
needed: no network, no dependencies, no secrets. Run it with:

```sh
python3 main.py
```
